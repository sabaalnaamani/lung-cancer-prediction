Introduction¶

Lung cancer is one of the most common cancers in the world [1]-[3]. It is the main cause of cancer deaths. It happens when lung cells grow abnormally and uncontrollably. Early stages of lung cancer usually do not show clear symptoms [1].

Problem statement¶

Most models rely only on individual patient data and ignore similarities between patients [7], [8], [9] . Some studies provide only a final prediction without confidence levels [21],[9]. Several studies do not use Explainable Artificial Intelligence (XAI) to explain feature impact [21], [13], [16], [12]. Many studies focus on accuracy, while sensitivity (recall) is more important in medical diagnosis to avoid missing cancer cases [16], [11], [22]. Hyperparameter tuning and synthetic sampling are often used without analyzing their effect on, stability, generalization, and bias [6], [23]. Also , counterfactual explanation to understand, manage risk.

Project objectives¶

1. Develop a hybrid ensemble learning model for lung cancer prediction using machine learning techniques.¶

2. Optimize and evaluate the models using appropriate performance metrics and threshold optimization.¶

3. Improve model reliability and explainability using PSI, DRZ, SHAP, and counterfactual analysis.¶

Explainable AI – XAI¶

1. PSI¶

Uses Mahalanobis Distance Identifies similar patients

2. DRZ¶

Confidence levels: High Medium Low

3. SHAP¶

Feature contribution explanation

4. Counterfactual Explanation¶

Minimal changes to reduce risk

ncols = 3
nrows = math.ceil(len(features) / ncols)

fig, axes = plt.subplots(
    nrows, ncols,
    figsize=(12, 3.8 * nrows)
)

axes = axes.flatten()

for ax, feature in zip(axes, features):
    data = lung_cancer[feature].dropna()

    if data.empty:
        ax.set_title(feature, fontsize=10)
        ax.text(0.5, 0.5, "No data",
                ha='center', va='center',
                transform=ax.transAxes)
        ax.axis('off')
        continue


    if pd.api.types.is_numeric_dtype(data):
        data.hist(
            ax=ax,
            bins=20,
            color='skyblue',
            edgecolor='black'
        )

        summary = (
            f"Mean: {data.mean():.2f} | "
            f"Median: {data.median():.2f}\n"
            f"Std: {data.std():.2f} | "
            f"Count: {data.count()}"
        )

    else:
        counts = data.astype(str).value_counts()
        counts.plot(
            kind='bar',
            ax=ax,
            color='lightcoral',
            edgecolor='black'
        )

        most_common = counts.index[0]
        frequency = counts.iloc[0]
        percentage = frequency / counts.sum() * 100

        summary = (
            f"Mode: {most_common}\n"
            f"Count: {frequency} | "
            f"Percentage: {percentage:.1f}%"
        )

    ax.set_title(feature, fontsize=10)
    ax.tick_params(axis='both', labelsize=8)
    
    ax.text(
        0.5, -0.28,
        summary,
        transform=ax.transAxes,
        ha='center',
        va='top',
        fontsize=8,
        bbox=dict(
            facecolor='white',
            edgecolor='gray',
            boxstyle='round,pad=0.4'
        )
    )


for ax in axes[len(features):]:
    ax.set_visible(False)

plt.tight_layout(h_pad=4, w_pad=2)
plt.show()
